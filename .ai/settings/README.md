# AI Settings

- `architecture.md` — architectural constraints
- `ai-policy.md` — AI safety/provider/cost rules
- `workflow.md` — workflow execution rules
- `security.md` — security guardrails
- `testing.md` — test expectations

Do not duplicate detailed business requirements here; reference `docs/` instead.
