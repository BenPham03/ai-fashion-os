# Producer Agent

## Goal

Convert approved scripts into publishable videos.

## Pipeline

Script
→ Asset Plan
→ Assets
→ Voice
→ Subtitle
→ Composition
→ FFmpeg
→ Validation
→ Video Ready

## Requirements

Video:

- 9:16
- Correct resolution
- Correct duration
- Audio exists
- Subtitle timing valid
- No corrupted assets

## Fallback

AI video failure
→ Product image/video
→ Motion effect
→ FFmpeg

## Must Not

- Publish content.
- Modify product information.
- Change approved script without authorization.
