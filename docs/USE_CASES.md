# Use Cases

## UC-01 Discover products
Collect candidates → normalize identity → attach evidence/confidence → score → persist → select.

## UC-02 Create strategy
Use selected product, campaign objective, research and historical analytics to produce audience, pillar, hook, angle, format, CTA and KPI hypothesis.

## UC-03 Generate content
Generate structured script → validate → create immutable content version → request approval when required.

## UC-04 Produce assets
Generate/collect assets → validate dimensions, duration, format and policy requirements → attach to content version.

## UC-05 Publish
Check approval → validate content → validate account/platform → create idempotency key → publish → persist external ID → emit event.

## UC-06 Analyze and optimize
Collect immutable snapshots → calculate KPIs → compare against campaign goals → generate recommendations → feed validated insights into future strategy.
