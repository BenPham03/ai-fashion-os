# User Stories

- As a Channel Operator, I want to create a campaign with an autonomy mode so I control how much automation is allowed.
- As a Channel Operator, I want product candidates scored with evidence so I can select products confidently.
- As a Channel Operator, I want AI to generate strategies and scripts so production is faster.
- As a Channel Operator, I want every generation saved as a version so I can compare and restore history.
- As a Channel Operator, I want approval gates so unsafe or low-quality content cannot be published.
- As a Channel Operator, I want scheduled publishing so content can be operated consistently.
- As a Channel Operator, I want duplicate publication prevented so retries cannot create duplicate posts.
- As a Channel Operator, I want analytics snapshots and optimization recommendations so future content improves from measured performance.
- As an Operator, I want AI token/cost tracking so the system stays within budget.
